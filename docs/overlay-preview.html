cachy-shortcuts · design preview

The overlay, running live in your browser

This container has no Wayland session and no GTK4 install, so the real ui/overlay.py can't be screenshotted here. Everything below reproduces its exact palette, type and layout, and the interactions are wired to real JavaScript rather than faked with a static image — try the arrow keys, search, and pressing Enter on a row.

What's real in this preview

  • Real: search filtering, grouped sections, arrow-key navigation (clamped, not wrapping, skips headers).
  • Real: the edit flow — Enter starts an in-place chord capture, Ctrl+Enter jumps straight to editing the command, n adds a new binding, d deletes with a y/Esc confirm. n/d are only mnemonics while the search box is empty — they're just letters once you're mid-search, exactly like the real overlay.
  • Real: live conflict feedback — composing a chord another row already owns turns the row amber and names the owner inline, no dialog.
  • Simulated: chord capture uses on-screen modifier chips instead of your actual physical keys — browsers can't reliably see the OS Super key, so this is the one place the preview substitutes a UI for the real key-listener in overlay.py.
  • Simulated: nothing here writes to a real config file. On the real machine every edit goes through the same snapshot → write → reparse → reload path already covered by the test suite.
